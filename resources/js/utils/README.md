# Utils Layer (Слой утилит)

## Назначение
Этот слой содержит **переиспользуемые вспомогательные функции** без состояния, которые используются по всему приложению.

## Правила
- ✅ **Чистые функции** без побочных эффектов
- ✅ **Переиспользуемые утилиты** (форматирование, валидация)
- ✅ **Низкоуровневые операции** (HTTP запросы, работа с данными)
- ❌ **НЕ содержит состояния** (ref, reactive)
- ❌ **НЕ содержит бизнес-логику** специфичную для домена

## Структура файлов

### api.js
Базовые функции для HTTP запросов:
- `apiGet()`, `apiPost()`, `apiPut()`, `apiDelete()`
- Обработка CSRF токенов
- Обработка ошибок API

### helpers.js
Общие вспомогательные функции:
- Форматирование дат и времени
- Работа с данными (debounce, deepClone)
- Валидация (email, пустые значения)
- UI утилиты (CSS классы, усечение текста)

## Пример использования

```javascript
// В API слое
import { apiGet, apiPost } from '@/utils/api.js'

// В UI компоненте  
import { formatDate, getStatusClass } from '@/utils/helpers.js'
```

## Взаимодействие с другими слоями
- **Используется**: Всеми слоями (API, UI, Features) и компонентами
- **Использует**: Только стандартные JS API и браузерные функции
