## Фаза 3: API Routes (1-2 дня)

### 3.1 Маршруты организаций
```php
// Управление организациями
Route::middleware(['organization:super_user'])->group(function () {
    Route::apiResource('organizations', OrganizationController::class)->except(['store']);
});

// Создание организации (регистрация + супер юзер)
Route::post('organizations', [OrganizationController::class, 'store'])
    ->middleware(['auth']);

// Управление участниками
Route::middleware(['organization:org_admin,super_user'])->group(function () {
    Route::apiResource('organizations.users', OrganizationUserController::class);
});

// Проекты в контексте организации  
Route::middleware(['organization:member'])->group(function () {
    Route::apiResource('organizations.projects', OrganizationProjectController::class);
});
```

## Критические зависимости

### Порядок выполнения:
1. **Фаза 1** должна быть завершена полностью перед началом других фаз
2. **Фаза 2** может выполняться параллельно с **Фазой 3**
3. **Фаза 4** зависит от завершения **Фаз 2-3**
4. **Фаза 7** выполняется только после полной готовности системы
5. **Фаза 8** проходит на каждом этапе

### Риски и митигация:
- **Риск**: Сложность миграции существующих данных
  **Митигация**: Создание детального плана миграции и тестирование на копии данных

- **Риск**: Производительность при больших объемах данных  
  **Митигация**: Правильная индексация и оптимизация запросов с самого начала

- **Риск**: Сложность переключения контекста в frontend
  **Митигация**: Использование Pinia store для централизованного управления состоянием
