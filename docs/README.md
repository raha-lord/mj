# Система управления задачами "MJ"

## Обзор проекта

**Система управления задачами "MJ"** - это полнофункциональное веб-приложение на Laravel для управления проектами и задачами с упором на точный учет времени и аналитику производительности.

### Основная функциональность

- **Управление задачами**: Создание, редактирование, удаление задач с расширенными возможностями
- **Система ролей**: Многоуровневое назначение исполнителей (assignee, observer, reviewer, manager)
- **Учет времени**: Детальное логирование времени выполнения задач
- **Размеры задач**: Система оценки сложности (XS, S, M, L, XL, Epic) с автоматическими рекомендациями
- **Фильтрация и поиск**: Расширенная система фильтров для задач
- **Управление проектами**: Организация задач по проектам
- **Аудит изменений**: Полное отслеживание всех изменений в системе

### Ключевые преимущества

- **Гибкая система ролей и назначений**: Возможность назначения нескольких пользователей на одну задачу с разными ролями
- **Автоматизированные рекомендации**: Система помогает оценить размер и сложность задач
- **Детальный учет времени**: Точное планирование и анализ времени выполнения
- **Расширенная фильтрация**: Быстрый поиск и группировка задач по различным критериям
- **Полный аудит**: Отслеживание всех изменений для анализа и отчетности
- **Масштабируемая архитектура**: Использование современных практик Laravel

### Целевая аудитория

- Команды разработки
- Проектные менеджеры  
- Малый и средний бизнес
- Организации, нуждающиеся в точном планировании и учете времени

## Техническая информация

- **Framework**: Laravel 10.x
- **База данных**: PostgreSQL
- **Frontend**: Livewire 3.4 + Tailwind CSS
- **Контейнеризация**: Docker + Docker Compose

## Быстрый старт

1. Клонируйте репозиторий
2. Настройте `.env` файл
3. Запустите Docker: `docker-compose up -d`
4. Выполните миграции: `docker-compose exec app php artisan migrate`
5. Создайте тестового пользователя
6. Откройте http://localhost:89
