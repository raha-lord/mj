## 🔄 Миграция с серверного HTML на Vue-компоненты

### **Текущий подход (серверный HTML):**

```php
// Laravel Controller
public function index() {
    $tasks = Task::paginate(20);
    return view('tasks.index', ['tasksHtml' => view('tasks.table', compact('tasks'))->render()]);
}
```

```javascript
// Vue компонент
const result = await getTasks(filters)
tasksHtml.value = result.html // HTML строка
```

```vue
<template>
  <div v-html="tasksHtml"></div> <!-- Небезопасно, нет реактивности -->
</template>
```

### **Vue-компонентный подход:**

```php
// Laravel API Controller
public function index(Request $request) {
    $tasks = Task::with(['status', 'project', 'assignees'])
        ->when($request->search, function($query, $search) {
            $query->where('name', 'like', "%{$search}%");
        })
        ->when($request->status, function($query, $status) {
            $query->where('status_id', $status);
        })
        ->paginate(20);

    return response()->json([
        'success' => true,
        'data' => TaskResource::collection($tasks),
        'meta' => [
            'current_page' => $tasks->currentPage(),
            'last_page' => $tasks->lastPage(),
            'total' => $tasks->total(),
        ]
    ]);
}
```

```javascript
// Composable
const result = await getTasks(filters)
tasks.value = result.data // JS объекты
```

```vue
<template>
  <TasksTable
    :tasks="tasks"
    :loading="loading"
    @view="openViewModal"
    @edit="openEditModal"
  />
</template>
```

## 🧩 Компонентная архитектура

### **1. Атомарные компоненты (shared/)**

```vue
<!-- Button.vue -->
<template>
  <button
    :class="buttonClasses"
    :disabled="loading"
    @click="$emit('click', $event)"
  >
    <LoadingSpinner v-if="loading" size="sm" />
    <slot v-else />
  </button>
</template>

<script setup>
defineProps({
  variant: { type: String, default: 'primary' },
  size: { type: String, default: 'md' },
  loading: { type: Boolean, default: false }
})

defineEmits(['click'])
</script>
```

### **2. Компоненты функций (tasks/)**

```vue
<!-- TaskRow.vue -->
<template>
  <tr class="hover:bg-gray-50 cursor-pointer" @click="$emit('view', task.id)">
    <td class="px-6 py-4">{{ task.name }}</td>
    <td class="px-6 py-4">
      <StatusBadge :status="task.status" />
    </td>
    <td class="px-6 py-4">
      <PriorityBadge :priority="task.priority" />
    </td>
    <td class="px-6 py-4">
      <div class="flex space-x-2">
        <Button
          size="sm"
          variant="outline"
          @click.stop="$emit('view', task.id)"
        >
          Просмотр
        </Button>
        <Button
          size="sm"
          variant="primary"
          @click.stop="$emit('edit', task.id)"
        >
          Изменить
        </Button>
      </div>
    </td>
  </tr>
</template>

<script setup>
defineProps({
  task: { type: Object, required: true }
})

defineEmits(['view', 'edit'])
</script>
```

### **3. Компоненты страниц**

```vue
<!-- TasksPage.vue -->
<template>
  <div class="space-y-6">
    <PageHeader title="Задачи">
      <Button @click="taskModal.openCreateModal()">
        Создать задачу
      </Button>
    </PageHeader>

    <TaskFilters
      v-model="tasksList.filters"
      @apply="tasksList.loadTasks"
      @clear="tasksList.clearFilters"
    />

    <TasksTable
      :tasks="tasksList.tasks"
      :loading="tasksList.loading"
      @view="taskModal.openViewModal"
      @edit="taskModal.openEditModal"
    />

    <TaskModal
      :is-open="taskModal.isOpen"
      :task="taskModal.task"
      :loading="taskModal.loading"
      :mode="taskModal.mode"
      @close="taskModal.closeModal"
      @save="handleTaskSave"
    />
  </div>
</template>

<script setup>
import { useTasksList } from '@/composables/features/useTasksList'
import { useTaskModal } from '@/composables/features/useTaskModal'

const tasksList = useTasksList()
const taskModal = useTaskModal()

const handleTaskSave = async (taskData) => {
  await taskModal.saveTask(taskData)
  await tasksList.loadTasks() // Обновляем список только при необходимости
}

// Загружаем задачи при монтировании
onMounted(() => {
  tasksList.loadTasks()
})
</script>
```

## 🔧 Ключевые принципы

### **1. Реактивность данных**
```javascript
// Автоматическое обновление UI при изменении данных
const updateTaskInList = (updatedTask) => {
  const index = tasks.value.findIndex(t => t.id === updatedTask.id)
  if (index !== -1) {
    tasks.value[index] = updatedTask // Vue автоматически обновит UI
  }
}
```

### **2. Изолированные состояния**
```javascript
// Каждый composable управляет своим состоянием
const tasksList = useTasksList()    // loading, tasks, filters
const taskModal = useTaskModal()    // loading, task, isOpen
const notifications = useNotifications() // messages, show, hide
```

### **3. События между компонентами**
```vue
<!-- Родительский компонент -->
<TasksTable @view="handleView" @edit="handleEdit" />

<!-- Дочерний компонент -->
<script setup>
const emit = defineEmits(['view', 'edit'])

const handleRowClick = (taskId) => {
  emit('view', taskId)
}
</script>
```

### **4. Переиспользование логики**
```javascript
// Общая логика модалок
export function useModal() {
  const isOpen = ref(false)
  const open = () => isOpen.value = true
  const close = () => isOpen.value = false
  return { isOpen, open, close }
}

// Специфичная логика задач
export function useTaskModal() {
  const modal = useModal()
  const task = ref(null)
  const loading = ref(false)

  return { ...modal, task, loading }
}
```

## ✅ Преимущества Vue-компонентного подхода

1. **Полная реактивность** - UI обновляется автоматически
2. **Переиспользование компонентов** - меньше дублирования кода
3. **Лучшая производительность** - обновляются только изменившиеся части
4. **Простота тестирования** - каждый компонент можно тестировать изолированно
5. **Типизация** - поддержка TypeScript из коробки
6. **Подготовка к WebSockets** - реактивные данные легко обновлять в реальном времени
